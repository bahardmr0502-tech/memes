A simple Discord bot developed with Python using the discord.py library.

This bot includes various fun and utility commands, such as mathematical operations, dice rolling, random choices, memes, animal images, and creative DIY ideas.

Features
Basic mathematical operations
Dice rolling
Random choices
Message repetition
Member join date information
Meme sharing
Random duck and fox images
Anime, gaming, and animal image categories
Random DIY and recycling ideas
Commands

Command	Description
?add	Adds two numbers
?roll	Rolls a dice
?choose	Chooses a random option
?repeat	Repeats a message
?joined	Shows a member's join date
?cool	Checks if someone is cool
?mem / ?mem2	Shares memes
?duck	Sends a random duck image
?fox	Sends a random fox image
?animals	Shares animal images
?gaming	Shares gaming images
?anime	Shares anime images
?idea	Suggests a creative DIY idea

Requirements
Python
discord.py
requests
Install dependencies:


bash
pip install discord.py requests
